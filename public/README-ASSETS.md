# Where to upload assets

| Folder | Put here |
|---|---|
| public/images/logo/ | Company logo (logo.svg / logo.png), favicon |
| public/images/hero/ | Large homepage banner photos (landscape, ≥1920px wide) |
| public/videos/hero/ | Homepage background video (hero.mp4, short loop, <15MB) |
| public/images/destinations/ | One photo per destination, named by slug: serengeti.jpg, ngorongoro.jpg, tarangire.jpg, kilimanjaro.jpg, zanzibar.jpg |
| public/videos/destinations/ | Destination videos, named by slug |
| public/images/wildlife/ | Animals: lion.jpg, elephant.jpg, migration.jpg ... |
| public/images/experiences/ | Activities: balloon-safari, cultural-visit, hiking ... |
| public/images/accommodation/ | Lodges, camps, hotels |
| public/images/gallery/ | Anything else for the gallery page |
| public/images/team/ | Staff / guide portraits |
